# Changelog

## v0.1.1

- Optional setup through Home Assistant's Add integration UI. / Optionale Einrichtung über Integration hinzufügen in Home Assistant.
- Import existing YAML configuration without changing the shared storage key. / Vorhandene YAML-Konfiguration übernehmen und den gemeinsamen Speicherpfad beibehalten.
- Central, persistent display-only calendar assignments with WebSocket synchronization. / Zentrale dauerhafte Anzeigezuordnungen mit WebSocket-Synchronisierung.
- Preserve assignments to calendars outside the editing card's selection. / Zuordnungen zu Kalendern außerhalb der bearbeitenden Karte erhalten.
- Complete setup translations for all nine supported languages. / Einrichtungstexte in allen neun unterstützten Sprachen vervollständigen.
